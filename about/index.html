What is Ceedoku?

Ceedoku is a free, lightweight, and open-source Sudoku game made by Ceebug. It is designed to fit your needs while using as few resources as possible, allowing Ceedoku to run on a wide range of devices. With plenty of features including multiple difficulty levels, dark mode, hints, saving, and more, Ceedoku gives you a simple yet powerful Sudoku experience.

Features:

  • Fully installable, right from your browser
  • Dark mode and light mode (Dark mode is default.)
  • Auto Sudoku generation
  • Works offline (After opening the installed version at least once with internet.)
  • Multiple difficulties (Easy, Medium, Hard, Expert, Master, Extreme, Impossible and Godlike)
  • Hints
  • Timer
  • Pencil mode
  • Erase mode
  • Game saving
  • Theme preference saving (Pick between dark and light mode, then have the game remember which mode you picked and switch to it next time you open the app.)
  • No ads
  • Pause on lost focus (Your game will be paused if you minimize, close, or otherwise make the app not visible.)
  • Best times
  • Hint cooldowns
  • Haptics
  • Sound effects
  • Animations
  • Settings menu (To control the features.)
  • Importing and exporting save files (Using .CSF (Ceedoku Save Format) for the save files.)
  • Clickable release version to direct to the changelogs
